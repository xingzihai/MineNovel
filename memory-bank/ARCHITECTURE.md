# MineNovel - AI 小说世界模拟器

> 一个基于世界推演的小说生成系统

## 核心理念

**InkOS 是工具流**：大纲 → 写 → 审 → 改
**MineNovel 是模拟器**：世界运行 → 切片呈现

---

## 架构概览

```
第六层：审核校验与读者反馈层（质检与市场）
┌─────────────────────────────────────────────────────┐
│  RAG校验  │  复查审核  │  读者耐心指数  │  反馈闭环  │
└─────────────────────────────────────────────────────┘
                          ↑ 输出
第五层：叙事渲染与节奏控制层（摄影机与后期）
┌─────────────────────────────────────────────────────┐
│  时期控制  │  叙事流速  │  情绪张力  │  文风控制    │
└─────────────────────────────────────────────────────┘
                          ↑ 呈现
第四层：故事编织与悬念控制层（剧本与导演）
┌─────────────────────────────────────────────────────┐
│  大纲系统  │  分卷系统  │  伏笔系统  │  填坑系统    │
└─────────────────────────────────────────────────────┘
                          ↑ 收束
第三层：角色智能体与状态推演层（演员与NPC）
┌─────────────────────────────────────────────────────┐
│  内驱力  │  情报隔离  │  关系矩阵  │  位置  │  资产  │
└─────────────────────────────────────────────────────┘
                          ↑ 行动
第二层：世界观与宏观法则层（环境舞台）
┌─────────────────────────────────────────────────────┐
│  世界法则  │  时间沙箱  │  天花板  │  敌意系数     │
└─────────────────────────────────────────────────────┘
                          ↑ 约束
第一层：基础设施与记忆计算层（底层基座）
┌─────────────────────────────────────────────────────┐
│  RAG向量库  │  状态机  │  Prompt组装  │  双层队列   │
└─────────────────────────────────────────────────────┘
```

## 从 InkOS 吸收的模块

### 直接复用（复制代码）

1. **`llm/provider.ts`** — LLM 调用、Stream 降级、错误处理
2. **`state/manager.ts`** 的文件锁和快照逻辑
3. **`agents/post-write-validator.ts`** — 11 条硬规则
4. **`agents/style-analyzer.ts`** — 风格指纹提取
5. **审计维度列表**（33 维度）

### 学习思路后重写

1. **Agent 基类设计**
2. **多模型路由**
3. **管线调度模式**

### 完全自建

1. 双层任务队列
2. 时间沙箱系统
3. 角色内驱力引擎
4. 情报隔离系统
5. 读者耐心指数
6. 读者反馈闭环
